한국어 개인정보처리방침

1. 운영자와 적용 범위

HTLee Studio는 OnSlope를 운영합니다. 이 방침은 Android의 스키장 탐색·검색·즐겨찾기·날씨 예보·리조트 사진·공식 웹캠/사이트 바로가기와 설정을 제공하는 Resorts 배포에 적용됩니다.

이 배포에는 GPS 활동 기록·백그라운드 위치 수집·지도 SDK/지도 타일 요청·회원가입/로그인·서버 동기화·결제·광고 SDK·분석 SDK·자동 오류 보고 전송 기능이 없습니다. 계정 자격정보·결제 정보·광고 식별자를 요구하지 않습니다. 별도 개발·테스트용 기록 기능은 이 방침의 적용 대상이 아니며, 공개 제공 전 방침과 필요한 고지를 갱신합니다.

2. 기기에서 처리하거나 저장하는 정보

  • 설정·즐겨찾기: 리조트 ID와 즐겨찾기 여부·순서·변경 시각, 탐색 국가·정렬, 언어·테마·대체 배경 선택, 오늘의 산 선택과 날짜, 위치 안내 확인 여부를 앱 전용 저장 공간에 보관합니다.
  • 목록·캐시: 내장 리조트 목록·사진 출처 정보를 읽고 기기에 저장하며, 날씨 예보·유효 시각·요청/갱신 상태를 캐시합니다. 실제 사진 파일은 일반 메모리 이미지 캐시로 표시합니다.
  • 검색·기기 지역: 검색어는 기기에서 검색에 사용하고 운영자 서버에 업로드하지 않습니다. 초기 언어·탐색 국가에는 기기의 언어·지역 설정을 사용합니다. 지역 설정은 GPS 위치가 아닙니다.

현재 운영자는 사용자별 설정·즐겨찾기·검색어·위치를 받는 자체 서버를 운영하지 않습니다. 외부 날씨·사진 요청과 사용자가 직접 보내는 이메일 문의는 아래와 같이 별도로 처리됩니다.

3. 선택적 위치 권한

앱에서 목적 안내 후 허용을 선택하면 Android의 대략적 위치 권한을 요청합니다. 가까운 순/먼 순 정렬은 전경에서 단발 조회한 위치와 공개 리조트 좌표로 기기 안에서 직선거리를 계산합니다. 위치·측정 시각·정확도는 메모리에서 처리하며, 조회한 위치는 최대 5분 동안 유효한 것으로 사용합니다. 이 유효 시간은 메모리의 즉시 삭제 시점을 뜻하지 않습니다.

앱은 이 사용자 위치를 앱 파일에 저장하거나 운영자·날씨·사진 서버에 전송하지 않습니다. 백그라운드에서 위치를 수집하거나 이동 경로를 기록하지 않습니다. 운영체제의 위치 서비스 자체 처리는 플랫폼·제공자의 정책을 따릅니다.

권한은 선택 사항이며 거부하거나 기기 설정에서 철회해도 기본 탐색·검색·즐겨찾기·리조트 예보를 사용할 수 있습니다. 위치가 없거나 위치 서비스가 꺼져 있으면 현재 위치에 따른 거리 정렬을 제공할 수 없습니다.

4. 날씨와 목록

날씨를 표시할 때 기기는 Norwegian Meteorological Institute(MET Norway)의 Locationforecast API에 HTTPS로 직접 요청합니다. 소수점 네 자리의 리조트 대표 좌표와 앱 공통 User-Agent, 조건부 갱신 정보 등 요청 메타데이터가 전달되고 네트워크 통신으로 접속 IP도 제공자에게 전달됩니다. 요청 좌표는 사용자의 GPS 위치가 아닙니다. 계정/광고 ID·검색어·즐겨찾기 전체 목록을 보내지 않습니다. 요청한 리조트는 요청 좌표로 드러날 수 있습니다.

MET API 약관은 직접 요청의 IP·요청 좌표가 로그에 남고 접속 로그가 노르웨이 Oslo의 자체 데이터센터에 보관된다고 설명합니다. MET 개인정보처리방침은 로그인 없는 기상 웹사이트의 IP를 최대 90일 보관하며 용량 관리·공격 및 운영 문제 탐지에 사용한다고 안내합니다. 제공자 로그의 보관·권리 요청은 해당 방침을 따릅니다.

예보 캐시와 요청 간격으로 불필요한 요청을 줄입니다. 최신 예보에는 인터넷이 필요하며 오프라인에서는 저장된 목록과 이용 가능한 예보를 사용합니다. 이 방침의 대상 배포는 원격 목록·사진 메타데이터 갱신 주소를 설정하지 않고 내장/기기 저장본을 사용합니다. 별도 카탈로그 CDN에 목록을 요청하지 않습니다. 원격 갱신을 활성화하기 전 실제 호스팅 제공자와 정보 처리를 이 방침에 반영합니다.

5. 사진과 외부 공급원

리조트 실사 표시는 Wikimedia Commons 이미지 서버(upload.wikimedia.org, thumb.wikimedia.org) 또는 Zermatt Bergbahnen AG의 공식 이미지 서버(www.matterhornparadise.ch)에 HTTPS로 직접 연결합니다. 이때 제공자·전달 인프라는 접속 IP·사진 요청 경로·앱 공통 User-Agent 등 요청 정보를 받을 수 있습니다. 사진 경로는 표시한 리조트를 나타낼 수 있습니다. 사용자 GPS·검색어·즐겨찾기 전체 목록은 보내지 않습니다.

앱은 자체 이미지 중계·사용자 사진 업로드 서버를 운영하지 않습니다. 사진별 작가·출처·라이선스·원본 링크는 설정의 앱 정보 및 법적 고지에서 확인할 수 있습니다. 내장 공통 설산 배경은 외부 이미지 요청 없이 표시합니다.

외부 접속 정보의 처리·보관·삭제는 Wikimedia 개인정보처리방침과 Zermatt Bergbahnen 데이터 보호 규정을 따릅니다. 운영자는 이 제공자들의 모든 로그 삭제 시점을 정하거나 대신 삭제할 수 없습니다.

6. 공식 웹캠과 외부 사이트

공식 웹캠·사이트·출처 링크는 시스템 브라우저 화면 또는 외부 브라우저로 엽니다. OnSlope는 웹캠 영상을 중계하거나 저장하지 않습니다. 방문한 사이트·영상 제공자·브라우저는 각자 정책에 따라 IP·쿠키·접속 정보를 처리할 수 있습니다. 해당 사이트의 방침과 선택 기능을 확인해 주세요. 일부 원본 링크는 HTTP일 수 있어 모든 외부 사이트의 암호화 연결을 보장하지 않습니다.

7. 보유 기간·삭제·백업

설정·즐겨찾기 정보는 변경하거나 앱 데이터를 지울 때까지 기기에 보관합니다. 즐겨찾기 해제는 활성 목록에서 제거하지만 해당 리조트 ID와 삭제 표시가 기기 파일에 남을 수 있습니다. 날씨 파일 캐시는 최근 요청한 리조트 좌표 항목 최대 100개로 제한하고 저장·갱신 시 교체합니다. 캐시의 예보 유효 시간이 곧 파일 삭제 시점은 아닙니다.

Android 설정에서 앱의 저장 공간/데이터를 지우거나 앱을 제거하면 기기의 앱 전용 데이터를 제거할 수 있습니다. 앱 데이터 지우기는 설정·즐겨찾기·파일 캐시를 함께 제거하며 되돌릴 수 없습니다. 위치 권한 철회는 저장된 즐겨찾기·설정의 삭제와 별개입니다.

운영체제·기기·백업 계정 설정에 따라 앱 데이터가 시스템 백업이나 기기 이전에 포함될 수 있습니다. 이는 OnSlope 자체 서버 동기화가 아닙니다. 앱 제거만으로 시스템 백업 사본·외부 서비스 로그가 모두 삭제되지는 않으며 시스템 백업은 플랫폼 설정과 정책으로 관리합니다. 기기 분실·재설치 후 로컬 정보 복구를 보장하지 않습니다.

8. 이용자의 선택과 문의

설정 변경·즐겨찾기 해제·기기 데이터 삭제·위치 권한 철회는 위 방법으로 직접 할 수 있습니다. 운영자에게 제공한 개인정보의 열람·정정·삭제·처리 중단 관련 문의는 htlee.studio@gmail.com으로 보내 주세요. 운영자는 받거나 보유하지 않은 기기 파일에 원격 접근할 수 없습니다. 외부 공급원의 접속 로그에 관한 권리 요청은 해당 공급원의 방침과 문의 경로를 이용해 주세요.

English Privacy Policy

1. Operator and scope

HTLee Studio operates OnSlope. This policy covers the Android Resorts distribution providing resort browsing, search, favorites, weather forecasts, resort photographs, links to official webcam pages/websites, and settings.

This distribution has no GPS activity recording, background location collection, map SDK/tile requests, account creation/sign-in, server synchronization, payments, advertising SDK, analytics SDK, or automatic crash-report uploads. It does not request account credentials, payment information, or advertising identifiers. Separate development/test recording features are outside this policy's scope; the policy and required notices will be updated before those features are publicly offered.

2. Information processed or stored on your device

  • Preferences and favorites: App-private storage holds resort IDs, favorite status/order/change time, country/sort preferences, language/theme/fallback background choices, the daily mountain selection/date, and whether the location introduction was seen.
  • Catalogs and caches: The app reads bundled resort catalogs/photo credits and stores them locally, together with cached forecasts, validity times, and request/update status. Photograph bytes use the normal in-memory image cache.
  • Search and device region: Search terms are used locally and are not uploaded to an operator server. Device language/region settings help select initial preferences; the region setting is not your GPS location.

The operator currently runs no server receiving your individual preferences, favorites, search terms, or device location. External weather/photo requests and emails you choose to send are handled separately as described below.

3. Optional location permission

After explaining the purpose, the app requests Android approximate-location permission if you choose to allow it. Nearest/farthest sorting calculates straight-line distances locally using a single foreground location fix and public resort coordinates. Location, measurement time, and accuracy are processed in memory; the fix is considered valid for up to five minutes. This validity period does not mean immediate deletion from memory at that time.

The app does not save this device location to app files or send it to the operator, weather servers, or image servers. It does not collect background locations or record routes. Processing by operating-system location services follows their platform/provider policies.

Permission is optional and can be declined or revoked in device settings. Browsing, search, favorites, and resort forecasts remain available. Sorting by distance from your current location cannot be provided without a usable fix or when location services are disabled.

4. Weather and catalogs

To display weather, your device makes direct HTTPS requests to the Norwegian Meteorological Institute (MET Norway) Locationforecast API. Requests include public resort coordinates rounded to four decimal places, a shared app User-Agent, and metadata such as conditional-update headers. Network communication also exposes your connection IP address. The coordinates describe a resort, not your GPS location. Account/advertising IDs, search terms, and your complete favorites list are not sent. Requested coordinates can reveal the resort being requested.

The MET API terms describe logging direct requests with IP addresses and requested coordinates, with access logs stored in MET's own data center in Oslo, Norway. The MET Privacy Policy describes retaining IP addresses for up to 90 days for weather websites without login, for capacity management and detecting attacks or operational problems. The provider's policy governs its logs and rights requests.

Caching and request intervals reduce unnecessary requests. Updated forecasts require internet access; saved catalogs and available forecasts can be used offline. The distribution covered here has no remote catalog/photo-metadata update URLs configured and uses bundled/saved data. It makes no catalog requests to a separate CDN. Before enabling remote updates, this policy will identify the actual hosting provider and processing.

5. Photographs and external providers

Resort photographs load directly over HTTPS from Wikimedia Commons image servers (upload.wikimedia.org, thumb.wikimedia.org) or Zermatt Bergbahnen AG's official image server (www.matterhornparadise.ch). Providers and delivery infrastructure may receive your connection IP address, image request path, shared app User-Agent, and other request metadata. The image path can identify the resort shown. Your GPS location, search terms, and complete favorites list are not sent.

The app operates no image relay or user-photo upload server. Photo authors, credits, licenses, and source links are available under Settings → About & legal. Bundled generic mountain backgrounds need no external image request.

External access data is governed by the Wikimedia Privacy Policy and Zermatt Bergbahnen Data Protection Regulations. The operator cannot determine or perform deletion of all logs held by these providers.

6. Official webcams and external websites

Official webcam, website, and attribution links open in a system browser view or external browser. OnSlope does not relay or store webcam video. Destination sites, video providers, and browsers may process IP addresses, cookies, and access information under their own policies. Review their policies and choices. Some source links may use HTTP; encrypted connections are not guaranteed for every external site.

7. Retention, deletion, and backups

Preferences and favorite information remain on the device until changed or app data is cleared. Unfavoriting removes a resort from the active list, but its ID and deletion marker may remain in local files. The weather file cache is limited to the 100 most recently requested resort-coordinate entries, replaced when saved/updated. Forecast expiry is not the same as file deletion.

Clearing app storage/data in Android settings or uninstalling can remove device-local app-private data. Clearing app data removes preferences, favorites, and file caches together and cannot be undone. Revoking location permission is separate from deleting saved favorites/preferences.

Operating-system, device, and backup-account settings may include app data in system backups or device transfers. This is separate from OnSlope server synchronization. Uninstalling does not remove every system backup copy or external service log. Manage system backups through platform settings and policies. Recovery of local information after device loss or reinstallation is not guaranteed.

8. Your choices and contact

You can change preferences, unfavorite resorts, clear device data, and revoke location permission as described above. For access, correction, deletion, or stopping processing of personal information provided to the operator, contact htlee.studio@gmail.com. The operator cannot remotely access device files it has not received or retained. For external provider logs, use that provider's policy and contact process.

When you email us, your sender address, message, and voluntary attachments are retained as needed to answer and troubleshoot, then deleted when no longer needed. Request deletion of support correspondence at the same address. Email is processed through Google Gmail; see the Google Privacy Policy. Do not include unnecessary location histories, sensitive information, or passwords.

GitHub may process IP addresses and request information to deliver and secure the page and operate its services. Processing, retention, and rights follow the GitHub Privacy Statement. Features of other website pages are separate from this policy page's processing.
